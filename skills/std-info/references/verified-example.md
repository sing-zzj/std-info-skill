## 样例验证过程中的关键事实（供后续复用）

- 标准封面不标注 ICS/CCS，各标准平台也未收录分类号 → 两字段留空，不得按"监理/工程建设"领域自行推测 P 类或 91 类。
- 该标准体例为工程建设标准：无独立"规范性引用文件"章，第 2 章是"术语"；规范性引用取自标准末尾"引用标准名录"（正文第 89 页），仅 2 项；输出时**只列标准号、顿号分隔**，不附名称。
- "替代标准号"填本标准替代的 DB33/T 1104-2014；本标准现行，"被替代标准号"留空。
- 发布日期 2022-10-13（公告落款日期）与公告网页发布日期 2023-02-06 不同，以公告原文落款为准。
- 字段顺序固定为：标准号 → 标准名称 → 标准英文 → **发布日期 → 实施日期 → 截止日期 →** CCS → ICS → 标准性质 → 状态 → 替代标准号 → 被替代标准号 → 归口单位 → 批准发布部门 → **起草单位 → 起草人 →** 规范性引用 → 实施范围。（三个日期紧跟标准英文；起草单位、起草人紧贴规范性引用上方，起草单位在上）
